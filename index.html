FEATURES.LOG

WHAT IT DOES

🔐

CONNECT OVER SSH

Standard SSH authentication against your existing server — no server-side agent, no persisted credentials, no extra setup.

📦

MANAGE MODELS

List, pull, stop, and delete installed models — batch-select multiple at once.

🖥

WATCH THE HOST

Live CPU, memory, disk, and GPU utilization, auto-refreshed on a configurable interval.

📜

READ THE LOGS

Tail journalctl or the server's log file directly — no separate SSH session needed.

🔁

RESTART THE SERVICE

Restart the Ollama service in one click, with automatic sudo fallback if needed.

💬

TEST PROMPTS

Send a request to any OpenAI-compatible endpoint and inspect the response, using the same model list you already manage.

💾

SAVE CONNECTIONS

Switch between multiple named SSH targets from a dropdown — each with its own optional saved password.

🌐

DEUTSCH / ENGLISH

Switch the entire UI between German and English live, no restart required.
